# wearable-stress-public-transport

Code, analysis protocols and supplementary material for the paper
**"Physiological Stress Patterns in Urban Public Transport"** (Cahuana-Nina, Cuela, Zavalaga Orozco; Universidad Nacional de San Agustín de Arequipa).

The pipeline converts the raw 20-byte BLE packets of an Empatica E4 wristband, logged with smartphone GPS and microphone level during bus trips in Arequipa, Peru, into synchronised 30-s windows, and evaluates whether physiology reveals the ride context (15 sessions, 4 volunteers).

## Data availability
The raw data (`DATAE4/`) contain GPS traces and exact timestamps and are **not** in this repository. They are available from the authors upon reasonable request. Place them in `DATAE4/<participant>/<session>/` to rerun the pipeline. Files with coordinates or timestamps (`ventanas.csv`, `gold*.csv`, `qc_e4.csv`, decoded signals) are regenerated locally and ignored by git.

## Reproduction
Python ≥ 3.10 (3.13 used), `pip install -r requirements.txt`; LaTeX for the paper. Everything is deterministic (seed 0).

| Step | Command | Output |
|---|---|---|
| 1 | `python decode_e4.py` | decoded signals, `salida/qc_e4.csv` |
| 2 | `python build_ventanas.py` | `salida/ventanas.csv` |
| 3 | `python clustering.py` | GOLD proxies, clustering grid |
| 4 | `python analisis_avanzado.py` | mixed models, classifiers, permutations |
| 5 | `python h2_parada_acc.py` | H2: stopped vs. moving from the wrist accelerometer |
| 6–7 | `python h1_ruido_fc.py`, `python h1_sensibilidad.py` | H1: heart rate after noise bursts |
| 8 | `python paper/make_figures.py && python paper/make_fig4.py` | figures |
| 9–11 | `python analisis_revision.py`, `perm_extra.py`, `perm_cluster.py` | review corrections, block permutations, Holm |
| 12 | `cd paper && python make_tables.py` | `tables/tab3.tex`, `supplement.tex` |

Check values: 1 498 candidate windows (P1 313, P2 847, P3 265, P4 73); effective rates PPG 64.006 Hz, ACC 32.003 Hz, temp 4.000 Hz, EDA 0.500 Hz, 0 % packet loss; H2 AUC 0.83 (block-permutation p = 0.0005, Holm 0.004); physiology-only balanced accuracy 0.30 / 0.34 / 0.24 (traffic / noise / exposure), all p ≥ 0.25.

## Limitations
The E4 binary formats are **inferred** (undocumented); PPG and EDA type B were not validated against a reference device. EDA type A (10-bit signal in a 12-bit field + 12-bit baseline code) could not be converted to µS and is excluded. Noise is the uncalibrated phone microphone level (dBFS). Code comments and some file names are in Spanish.
